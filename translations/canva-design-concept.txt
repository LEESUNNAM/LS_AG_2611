# Canva 디자인 컨셉

주제 하나를 승인 관문 두 개를 거쳐 완성된 Canva 디자인으로 정리해 두는 데까지 고정된 순서로 진행합니다. 컨셉을 승인받기 전에는 아무것도 만들지 않고, 초안을 승인받기 전에는 아무것도 저장하지 않습니다.

Canva 도구는 사용자 계정에 실제 디자인과 폴더를 만듭니다. 관문이 있는 이유입니다. 요청이 완결돼 보여도("X 주제로 포스터 만들어줘") 관문을 건너뛰지 마세요. 컨셉은 먼저 승인받아야 합니다.

## 도구

Canva 도구는 지연 로드 방식입니다. 첫 호출 전에 ToolSearch로 스키마를 로드하고, 필요한 도구를 한 번에 모두 로드하세요. 예:

`select:mcp__Canva__create-design,mcp__Canva__get-create-design-async-job,mcp__Canva__read-design,mcp__Canva__edit-design,mcp__Canva__search-folders,mcp__Canva__create-folder,mcp__Canva__get-export-formats,mcp__Canva__export-design,mcp__Canva__move-item-to-folder`

| 단계 | 도구 |
|---|---|
| 초안 생성 | `create-design`, 이어서 `get-create-design-async-job` |
| 초안 확인·수정 | `read-design`, `edit-design` |
| 폴더 찾기·만들기 | `search-folders`, `create-folder` |
| 내보내기 | `get-export-formats`, `export-design` |
| Canva 계정에 정리 | `move-item-to-folder` |
| 독립 이미지만 필요할 때 | `generate-image` (사용자가 디자인된 페이지가 아니라 이미지, 일러스트, 아이콘을 요청하면 `create-design` 대신 사용) |

Canva 호출에는 항상 `user_intent`를 넣으세요. 사용자가 자신의 브랜드 키트나 브랜드 템플릿을 적용하길 원하는 경우가 아니면 레거시 생성기(`generate-design`, `generate-design-structured`, `request-outline-review`)는 쓰지 마세요. 전체 도구 설명은 `research/canva-mcp-tools.md`를 참고하세요.

## 작업 순서

### 1. 컨셉 제안 (Canva 호출 없음)

주제를 바탕으로 **최소 3가지**의 서로 다른 컨셉을 제안합니다. 같은 레이아웃에 색만 바꾼 것이 아니라 정말 다른 방향이어야 합니다. 컨셉마다 다음을 적습니다.

- 이름과 한 줄 요약
- 무드
- 컬러(hex 값)
- 폰트 방향
- 레이아웃 접근
- 가장 어울리는 용도

하나의 표에 나란히 보여 주고, 직접 고른다면 어느 것인지와 이유를 한 문장으로 밝힌 뒤 어떤 것으로 진행할지 묻습니다. 그리고 멈춥니다. 이 단계에서는 Canva 도구를 호출하지 않으며, 사용자가 컨셉을 승인하기 전에는 아무것도 만들지 않습니다. 사용자가 수정을 요청하면 고쳐서 다시 제시합니다.

### 2. 만들 작업물 확인

컨셉이 승인되면, 사용자가 아직 말하지 않았을 경우 어떤 작업물을 원하는지 묻습니다. 포스터, 프레젠테이션, 인스타그램 게시물, 문서, 전단지 등입니다. 승인과 함께 이미 말했다면("B, 포스터로") 다시 묻지 않습니다.

결과에 영향을 주는 사항도 한 번에 간단히 확인합니다. 프레젠테이션이면 페이지(슬라이드) 수, 사용자가 원하는 문구가 따로 있으면 정확한 텍스트입니다.

### 3. 초안 생성

`create-design`의 브리프는 사용자의 언어로 작성합니다. 도구는 앞선 대화를 보지 못하므로, 승인된 컨셉을 브리프 안에 풀어서 적어야 합니다.

- 주제와 목적
- 컨셉의 무드, hex 컬러, 폰트 방향, 레이아웃 접근
- 제목, 부제, 섹션, 마무리 문구의 정확한 문구 (사용자가 주지 않았으면 주제에서 직접 작성)
- "확인되지 않은 수치, 제품명, 로고는 넣지 않는다"

`format`에는 방향을 포함해 지정합니다. 예: `Poster (Portrait)`. 프레젠테이션은 구조를 우연에 맡기지 말고 `outline.sections`를 넘깁니다.

`create-design`은 비동기입니다. 각 `get-create-design-async-job` 호출 전에 `polling_policy.wait_seconds`만큼 기다리세요(처음 15초, 이후 약 10초). 더 일찍 호출하면 같은 답이 돌아옵니다. Bash 도구는 foreground sleep을 막으므로 대기에는 PowerShell의 짧은 `Start-Sleep`을 씁니다.

생성기는 요청하지 않은 텍스트를 덧붙이는 경향이 있습니다(추가 문구, 반복되는 부제, 표지의 예시 체크리스트 등). 브리프에 "이 문구만 사용하고 다른 텍스트는 추가하지 않는다"를 넣어 줄이되, 일부는 여전히 생길 수 있다고 보세요.

공유하기 전에 `read-design`을 `design_metadata`, `design_content`로 호출해 텍스트를 요청한 내용과 비교합니다. 덧붙었거나 순서가 바뀐 텍스트는 초안이 정확하다고 말하지 말고 사용자에게 목록으로 알려 줍니다. 줄바꿈 때문에 `design_content`에서 제목이 띄어쓰기 없이 읽힐 수 있으므로(예: "생산성습관"), 내보낸 이미지를 보기 전에는 오타로 보고하지 마세요. 그다음 사용자에게 다음을 전달합니다.

- 편집 링크와 보기 링크
- 제목과 페이지 수
- 확인한 것(텍스트)과 확인하지 못한 것(내보내기 전에는 볼 수 없는 레이아웃과 색감)

초안은 사용자의 Canva 계정에 자동 저장됩니다. 그 사실을 알리고, 수정할지 저장할지 묻습니다.

### 4. 요청 시 수정

변경 요청이 있으면 `read-design`(`open_transaction: true`, `thumbnails` 포함)으로 편집 트랜잭션을 열고, `edit-design`을 `finalize: "keep_open"`으로 적용한 뒤 결과를 보여 주고, 사용자가 승인한 후에만 `commit` 합니다. commit은 되돌릴 수 없습니다.

### 5. 최종 저장 (사용자가 승인한 뒤에만)

"저장해줘", "승인", "이대로 좋아" 같은 말을 승인으로 봅니다. 그다음 순서대로 진행합니다.

1. `search-folders`로 `canva`라는 폴더를 찾습니다. 없을 때만 `create-folder`(상위 `root`)로 만듭니다.
2. `canva` 안에 **주제를 폴더명으로** 하여 `create-folder`로 하위 폴더를 만듭니다.
3. 해당 디자인에 대해 `get-export-formats`로 `png`가 있는지 확인한 뒤, `export-design`을 `format: {"type": "png"}`로 호출합니다. 이 디자인이 PNG를 지원하지 않으면 조용히 바꾸지 말고 사용자에게 알리고 가장 가까운 형식을 제안합니다.
4. 반환된 URL마다 `curl -sL -o`로 로컬 폴더 `canva/<주제>/`에 내려받습니다. URL은 서명된 일시 URL이라 만료되므로 바로 내려받고 따옴표로 감쌉니다. 여러 페이지 디자인은 페이지마다 URL이 하나씩 반환되며, `<이름>-1.png`, `<이름>-2.png`처럼 저장합니다.
5. 각 파일이 실제 PNG인지 확인하고(`file <경로>`) 이미지를 직접 봅니다. 이상한 점이 있으면 보고합니다.
6. `move-item-to-folder`로 디자인을 Canva의 `canva/<주제>` 폴더에 정리합니다.

파일 이름은 주제와 작업물에서 따옵니다. 예: `AI-도구-포스터.png`. 주제와 파일 이름에 Windows 경로에서 쓸 수 없는 문자(`\ / : * ? " < > |`)가 있으면 바꿉니다.

## 틀리기 쉬운 규칙

- **관문 두 개.** 3단계 전에 컨셉 승인, 5단계 전에 저장 승인. 사용자가 초안을 마음에 들어 하는 것만으로는 저장하라고 말하지 않은 이상 저장 승인이 아닙니다.
- **작업물을 추측하지 않습니다.** 승인 후에도 불분명하면 묻습니다.
- **확인하지 못한 것은 말합니다.** 텍스트는 읽을 수 있지만 PNG가 나오기 전에는 레이아웃을 볼 수 없습니다. 초안 링크를 줄 때 그렇게 밝히세요.
- **중복을 만들지 않습니다.** `canva` 폴더를 만들기 전에 먼저 찾고, 사용자가 새로 요청하지 않는 한 초안을 하나 더 만들지 않습니다.
- **동영상은 범위 밖입니다.** `create-video`는 사용자의 월 AI 한도를 쓰고 별도의 명시적 확인이 필요합니다. 이 흐름에 섞지 말고 따로 제안하세요.

## 확인된 동작

전체 흐름을 거친 테스트를 두 번 실행했습니다.

**포스터, 주제 "AI 도구"**
- 컨셉 3가지를 먼저 제시했고, 사용자가 하나를 승인하며 포스터를 선택했습니다.
- hex 컬러와 정확한 문구를 넣은 한국어 브리프로 `create-design`을 호출하자 텍스트가 브리프와 일치하는 1페이지 포스터가 만들어졌습니다. 라인 아이콘은 생성기가 스스로 추가했습니다.
- 작업은 약 25초 걸렸습니다(15초 대기 후 10초 대기).
- PNG로 `export-design`을 호출하자 서명된 URL 하나가 반환됐고, 파일은 2304 x 3456이었습니다.

**프레젠테이션, 주제 "생산성 습관", 3장**
- `create-design`을 `format: "Presentation"`과 `outline.sections` 3개로 호출하자 승인된 컨셉대로 3페이지 덱이 만들어졌습니다. 세 슬라이드가 같은 색과 노트북 스타일을 유지했습니다.
- 작업은 약 70초 걸렸고 상태 조회가 4번 필요했습니다(15초, 이후 10초씩).
- 텍스트는 아웃라인과 일치했지만 생성기가 텍스트를 덧붙였습니다. 슬라이드 1의 문구 줄, 슬라이드 2와 3의 반복되는 부제, 체크리스트 제목, 달라진 체크리스트 순서입니다. 저장 전에 사용자에게 알렸습니다.
- PNG로 `export-design`을 호출하자 페이지마다 하나씩 서명된 URL 3개가 반환됐습니다. 각 파일은 유효한 1920 x 1080 PNG였고 `<이름>-1.png`부터 `<이름>-3.png`로 저장했습니다.

**두 번 모두**
- `get-export-formats`는 `pdf`, `jpg`, `png`, `pptx`, `gif`, `mp4`를 나열했습니다.
- 계정에 `canva` 폴더가 이미 있어서 매번 주제 하위 폴더만 새로 만들었습니다.
- 아직 확인하지 못한 것: 문서의 PNG 내보내기, `edit-design`으로 초안 수정.
