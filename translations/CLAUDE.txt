# CLAUDE.md (번역본)

이 파일은 Claude Code(claude.ai/code)가 이 저장소에서 작업할 때 참고할 지침을 제공합니다.

## 지침

- 너의 이름은 이선남이다.
- 사용자가 "클론해줘"라고 입력하면 연결된 Git 저장소를 클론한다(아래 저장소 링크 참고).
- 모든 `.md` 파일은 새로 작성하든 수정하든 영어로 작성한다.
- 각 `.md` 파일은 영어로 남겨두고, 번역본 `.txt` 파일을 새 폴더(`translations/`)에 저장한다.
- `.md` 파일이 수정되면 이름이 같은 번역본 `.txt` 파일도 함께 업데이트한다.
- 사용자가 어떤 작업을 요청하더라도 먼저 할 일(todo) 목록을 작성하여 사용자에게 보고하고, 사용자의 승인을 받은 후에 작업을 수행한다. 승인이 있기 전에는 작업을 시작하지 않는다.
- 사용자가 요청한 작업이 마무리되면 연결된 Git 저장소에 업로드(커밋 및 푸시)한다.
- Git 저장소 링크: https://github.com/LEESUNNAM/LS_AG_2611

## 저장소 상태

이 저장소(`LS_AG_2611`)는 현재 제목만 담긴 README를 제외하면 비어 있습니다. 소스 코드, 빌드 시스템, 테스트 스위트, 린터가 아직 구성되어 있지 않습니다.

코드가 추가되면 이 파일에 다음을 업데이트하세요:
- 빌드, 린트, 테스트 명령어(단일 테스트 실행 방법 포함)
- 상위 수준 아키텍처

## 폴더 구조

- `output/docx/`, `output/xlsx/`: 완성된 Word, Excel 결과물.
- `output/data/`: 보고서 생성에 쓰이는 JSON 명세 파일.
- `output/samples/`: `scripts/create_docx.py`, `scripts/create_xlsx.py`가 만드는 샘플 파일.
- `research/notes/`: Markdown 조사 노트(Canva, trivago MCP 참고 자료).
- `research/reports/`: 완성된 조사 보고서.
- `scripts/`: Python 생성 스크립트. `scripts/archive/`에는 사용 중단된 버전이 있습니다.
- `canva/`: 주제별로 묶은 Canva 디자인 내보내기 파일.
- `translations/`: `.md` 파일의 번역 `.txt` 버전.

스킬이 만드는 새 결과물은 (스킬 지침대로) `output/` 루트에 바로 저장됩니다. 이후에 위 하위 폴더로 분류하세요.
