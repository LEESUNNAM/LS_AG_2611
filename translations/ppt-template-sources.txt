# 상업적 이용이 가능한 무료 PPT 템플릿 출처 (2026-11-06 확인)

무료 발표자료 템플릿을 제공하는 사이트별로, 사이트 자체의 라이선스 또는 약관 페이지가 상업적 이용에 대해 무엇이라고 말하는지 정리한 노트이다. 모든 행은 2026-11-06에 Playwright MCP로 각 사이트의 공식 라이선스 또는 약관 페이지에서 확인했다. Google 검색 결과의 블로그 모음 글은 근거로 쓰지 않았다.

> 이 노트는 조사 메모이며 법률 자문이 아니다. 사이트 정책은 바뀔 수 있으므로, 유료 프로젝트에 쓰기 전에 링크된 페이지를 다시 읽어야 한다.

## 요약

| 사이트 | 무료 | 상업적 이용 | 출처 표기 의무 | 판정 |
|---|---|---|---|---|
| SlidesCarnival | 예, 가입 불필요 | 가능 (CC BY 4.0) | 예, 크레딧과 링크 | 출처 표기 시 사용 가능 |
| Slidesgo | 예 (Premium 요금제 있음) | 편집 불가능 형식 결과물에 한해 가능 | 예, 출처 표기 슬라이드 유지 | 출처 표기 시 사용 가능 |
| Canva (무료 콘텐츠) | 예 | 명시된 용도에 한해 가능 | 확인한 라이선스 본문에는 요구 없음 | 사용 가능, Pro 표시 항목은 피할 것 |
| 미리캔버스 | 무료 및 유료 항목 | 계약이 정한 범위 안에서 가능 | 포트폴리오 사용 시에만 | 사용 가능, 요금제별 제한은 미확인 |
| Microsoft 템플릿 | 예 | 확인되지 않음 | 확인하지 않음 | 상업적 이용 전에 확인 필요 |

## 상세

### 1. SlidesCarnival
- 주소: https://www.slidescarnival.com/ (약관: https://www.slidescarnival.com/terms-of-use)
- 형식: PowerPoint와 Google Slides. 메인 페이지에 "Free for any use, no registration"이라고 적혀 있다.
- 라이선스: "All templates by SlidesCarnival are free to use under Creative Commons License Attribution 4.0 International." 약관은 자료를 "for any purpose, even commercially" 변형해 쓸 수 있다고 한다.
- 조건: 적절한 크레딧과 웹사이트 링크를 제공해야 한다. 템플릿에 사진이 포함된 경우 사진에는 별도 라이선스가 있으므로 Credits 슬라이드를 유지해야 한다.
- 제한: 파일을 수정 없이 그대로 재판매, 재라이선스, 재배포할 수 없다. 템플릿으로 만든 발표자료는 자신의 콘텐츠를 더한 경우에만 재판매 또는 재배포할 수 있다.
- 참고: 약관 페이지 본문은 서비스 제공자로 Canva를 명시하고 있다.

### 2. Slidesgo
- 주소: https://slidesgo.com/ (약관: https://slidesgo.com/terms-conditions, 7조)
- 형식: Google Slides 테마와 PowerPoint 템플릿(메인 페이지 제목). 일부 템플릿은 Premium 사용자 전용 추가 슬라이드가 있다.
- 라이선스: 7.2항은 편집 불가능 형식의 가공 콘텐츠를 "개인, 전문, 상업, 교육, 광고 또는 마케팅 발표"에 쓰는 것을 허용하며, 제품에 포함해 판매하는 발표자료도 포함한다.
- 조건: 웹사이트가 생성한 출처 표기 부분을 발표자료에서 지우면 안 된다. 출처 표기를 생략할 수 있는 라이선스(Premium 구독)를 얻은 경우에만 제거할 수 있다.
- 제한: 템플릿이나 편집 가능한 가공 콘텐츠를 재판매, 양도, 재라이선스할 수 없다. 편집 가능한 파일은 발표자료를 만드는 팀과만 공유할 수 있다.
- 운영사: Freepik Company, S.L.U.

### 3. Canva (무료 콘텐츠 라이선스)
- 주소: https://www.canva.com/policies/content-license-agreement/
- 라이선스: 무료 콘텐츠는 비용 없이 라이선스된다(영구, 비독점, 전 세계). 허용 용도에는 광고·홍보 프로젝트와 프레젠테이션이 포함된다.
- 주의: Canva는 일부 콘텐츠를 Pro로 표시하며, Pro는 유료이고 디자인 1건에만 유효하며 단독 항목으로 배포할 수 없다. 브랜드 콘텐츠는 더 엄격한 규칙을 따르며, 여러 종류를 섞은 디자인에는 가장 엄격한 규칙이 적용된다.
- 미확인: 계정이 필요한지, 특정 템플릿이 `.pptx`로 깔끔하게 내보내지는지.

### 4. 미리캔버스
- 주소: https://www.miricanvas.com/ (라이선스 계약, 시행일자 2023-09-11: https://www.miricanvas.com/s/119)
- 계약이 든 허용 예시: 발표나 강의용 프레젠테이션 디자인, 편집 불가능한 PPT 형식의 기업 홍보 자료 또는 프로젝트 보고서 디자인. 다운로드한 PPT는 PowerPoint에서 제한적으로 편집할 수 있다(위치·크기 변경, 삭제, 애니메이션, 페이지와 텍스트 추가).
- 조건: 포트폴리오에 쓸 때는 해당 서비스로 만든 것임을 분명히 표시해야 한다.
- 제한: 콘텐츠의 재라이선스, 재판매, 재배포 금지, 스톡 이미지 사이트와 크리에이터 마켓 게시 금지, 상표 등록 로고로 사용 금지.
- 무료 공급자 콘텐츠(공유마당, 공공누리, Pixabay, Pexels)는 각 항목의 상세 정보에 표시된 공급자 라이선스를 따른다.
- 미확인: 무료 요금제와 Pro 요금제의 상업적 이용 허용 범위가 다른지. 라이선스 페이지에는 나와 있지 않다. 프로젝트가 이에 달려 있다면 서비스에 문의해야 한다(페이지에 miricanvas@miricanvas.com이 적혀 있다).

### 5. Microsoft PowerPoint 템플릿
- 주소: https://powerpoint.cloud.microsoft/create/en/presentation-templates/ (create.microsoft.com이 이동하는 주소)
- 페이지는 "무료 슬라이드 템플릿"을 제공한다고 한다. 페이지에 있는 유일한 약관 링크는 Microsoft 이용약관으로 이어지며, 여기에는 "별도 명시가 없으면 서비스는 개인적이고 비상업적인 용도"라고 되어 있다.
- 읽은 페이지에서는 템플릿의 상업적 이용을 허용한다는 문장을 찾지 못했다. Microsoft 서비스 계약과 템플릿별 약관은 읽지 않았으므로, 상업적 이용은 확인되지 않은 것으로 취급한다.

## 방법과 한계

- 검색: Google(한국어 검색어 "무료 PPT 템플릿 상업적 이용 가능") 후, 후보 사이트의 공식 라이선스 페이지.
- 각 라이선스 페이지의 텍스트는 키워드(commercial, attribution, resale 등)로 걸러 해당 구절을 읽었다. 키워드에 걸리지 않은 조항은 전부 읽지 않았다.
- Slidesgo는 처음 추측한 약관 주소가 404여서, 메인 페이지의 링크를 사용했다.
- 각 라이선스 페이지의 스크린샷은 `output/playwright/`에 로컬로 보관한다(`ppt-license-*.png`, `ppt-search-google.png`).
- 다루지 않은 곳: Google Slides 자체 템플릿 갤러리, Freepik, 미리캔버스 외 국내 서비스.
