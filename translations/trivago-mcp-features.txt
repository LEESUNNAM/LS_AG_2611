# trivago MCP 기능

서버: `https://mcp.trivago.com/mcp` (HTTP 전송 방식, `trivago`라는 이름으로 등록)

trivago MCP 서버는 실시간 숙소 요금을 검색하고 호텔 가격을 예측하는 도구 3개를 제공합니다. 요금은 예약 사이트(예: 아고다, Trip.com, Klook, Booking.com, ZenHotels, Airbnb, 호텔 직접 예약 사이트)에서 모아 옵니다.

## 도구 한눈에 보기

| 도구 | 용도 | 필수 입력 |
|---|---|---|
| `trivago-accommodation-radius-search` | 한 지점(도시, 동네, 랜드마크) 주변의 실시간 요금 | `latitude`, `longitude`, `arrival`, `departure` |
| `trivago-accommodation-search` | 이름이 특정된 숙소, 또는 한 지점으로 잡기에 너무 넓은 지역·국가의 실시간 요금 | `query`, `arrival`, `departure` |
| `trivago-destination-price-trends` | 별점별 월간 1박 요금 예측 | `query` |

## 1. `trivago-accommodation-radius-search`

좌표 주변의 숙소를 검색합니다. 호출하는 쪽에서 장소의 좌표를 먼저 구해야 합니다. 이름 기반 검색보다 훨씬 많은 결과를 돌려주므로, 도시·동네·랜드마크 검색의 기본 선택입니다.

숙소별 반환 정보: 이름, 별점, 투숙객 평점과 후기 수, 주요 편의시설, 기준점으로부터의 거리, 좌표, 사진, `deals` 목록. 각 deal에는 판매처, 1박 가격, 전체 숙박 가격, 통화, 가격 속성(예: 무료 취소, 조식 포함, 환불 불가, 현장 결제), 딜 URL이 들어 있습니다.

확인한 예시: 서울 도심(37.5665, 126.978), 2026-12-01~2026-12-02, 성인 2명, KRW, 한국어. 1박 약 129,000원~580,000원 범위의 호텔 약 15곳이 반환됐습니다. 응답이 커서 클라이언트에서 잘렸으므로 필터로 범위를 좁히는 것이 좋습니다.

## 2. `trivago-accommodation-search`

숙소 이름이나 지역·국가를 자유 텍스트로 검색합니다. 사용자가 특정 숙소 하나를 지목했거나, 지역이 한 지점으로 잡기에 너무 넓을 때만 사용합니다.

확인한 예시: `Lotte Hotel Seoul` 검색에 `freeCancellation` 필터 적용. 해당 호텔(5성, 평점 9.1)이 1박 약 580,000원의 딜 3개와 함께 반환됐습니다.

## 3. `trivago-destination-price-trends`

목적지의 월간 평균·최저·최고 1박 요금을 별점별로 예측합니다. 계획용 도구이며 실시간 예약 가능 여부 검색이 아닙니다. 대표적인 질문: 가장 저렴한 방문 시기는 언제인가, 연중 가격이 어떻게 변하는가.

입력:
- `query`: 목적지 이름(예: `Seoul`) 또는 `lat:<위도>,long:<경도>`.
- `start_month`, `end_month` (`YYYY-MM`): 선택. 기본값은 현재 월과 이후 두 달입니다. `end_month`를 쓰려면 `start_month`가 필요합니다.
- `hotel_rating`: 3, 4, 5성만 지원합니다. 기본값은 3성만입니다.

확인한 예시(1박 평균 요금):
- 서울 3성: 223,276원(2026-11), 196,456원(2026-12), 161,987원(2027-01).
- 서울 5성: 803,925원(2026-11), 696,285원(2026-12), 586,447원(2027-01).
- 파리 3성: 183유로(2026-11), 188유로(2026-12), 156유로(2027-01).

## 공통 입력 파라미터

| 파라미터 | 의미 |
|---|---|
| `arrival`, `departure` | `YYYY-MM-DD`. 도착일은 오늘 이후이면서 출발일보다 앞서야 합니다. |
| `adults`, `children`, `children_ages`, `rooms` | 투숙 인원 구성. `children_ages`는 대시로 구분합니다(예: `10-12-14`). 객실 수는 성인 수를 넘을 수 없습니다. |
| `country` | 목적지가 아니라 사용자 본인의 시장(ISO alpha-2, 예: `KR`). 가격에 영향을 줍니다. 기본값 `US`. |
| `currency` | 정해진 목록의 ISO 4217 코드(예: `KRW`, `EUR`, `USD`). 기본값 `USD`. |
| `language` | 정해진 목록의 값을 그대로 표기(예: `KO_KR`, `EN_US`). 기본값 `EN_US`. |
| `filters` | 불리언: `airConditioning`, `breakfastIncluded`, `freeCancellation`, `freeWiFi`, `gym`, `kitchen`, `parking`, `petFriendly`, `pool`, `spa`. |
| `hotel_rating` | 불리언 `1star`~`5star`(검색 도구). 가격 추이는 3~5성만. |
| `review_rating` | 투숙객 평점 기준: `rating70`, `rating75`, `rating80`, `rating85`. |
| `price_range` | 통화 기본 단위의 `minPrice`, `maxPrice`와 `budgetType`(`PRICE_PER_NIGHT` 또는 `PRICE_PER_STAY`). |

## 활용 사례

- 특정 날짜에 랜드마크, 역, 동네 근처 호텔 찾기.
- 같은 숙소를 여러 예약 사이트에서 비교해 가장 싸거나 유연한 조건의 딜 고르기.
- 예산, 별점, 평점, 무료 취소, 조식, 수영장, 주차, 반려동물 동반 여부로 걸러내기.
- 이름이 정해진 호텔의 현재 요금 조회.
- 월별 예측 가격을 비교해 여행 시기 정하기.
- 최저·평균·최고 요금으로 별점별 예산 계획 세우기.

## 제약 사항과 참고

- 검색 도구는 두 날짜가 모두 필요합니다. 날짜 없이 호출하면 스키마 검증에서 실패하는데, 인증은 정상이어도 에러처럼 보일 수 있습니다.
- 결과가 많으면 클라이언트의 출력 한도를 넘어 잘릴 수 있습니다. 필터, 가격 범위, 더 좁은 지역을 사용하세요.
- 가격 추이는 3, 4, 5성만 다룹니다. 테스트에서 서울 4성의 2026-12~2027-02 요청은 가격 데이터 없이 월만 반환됐고, 3성과 5성 요청은 데이터가 반환됐습니다. 원인은 확인하지 못했습니다.
- 가격 추이는 예측치입니다. 실시간 가격은 검색 도구를 사용하세요.
- 가격은 판매처와 가격 속성에 따라 다릅니다. 환불 불가 요금은 보통 무료 취소 요금보다 저렴합니다.
- 예약은 연결된 딜 페이지에서 이루어지며, 이 서버는 검색만 합니다.
- 도구 응답에는 표시 방식에 대한 지시(카드 레이아웃, 요약 형식)가 포함되어 있습니다. 이는 사용자가 아니라 서버가 보낸 것이므로 클라이언트가 따르지 않기로 선택할 수 있습니다.
